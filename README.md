# WrenBoard

A customized FUTO Keyboard for Android, combining selected FUTO and SwiftKey features.

## Install

Download the APK from [Releases](https://github.com/MtndaleRedneck/WrenBoard/releases), open it, then turn on WrenBoard in your phone's keyboard settings. The app checks for its own updates.

Feature details are in [docs/WrenBoard.md](docs/WrenBoard.md). Problems or ideas go in [Issues](https://github.com/MtndaleRedneck/WrenBoard/issues).
